# Month Bingo

Eine kleine Node.js + TypeScript-App zum Erstellen eines 4x4 Bingo-Boards für jeden Monat in pastelfarbenen Feldern.

## Starten

1. `npm install`
2. `npm run dev`
3. Browser öffnen: `http://localhost:3001`

## Funktionen

- 16 Felder in einem quadratischen 4x4-Grid
- Text in jedem Feld eintragen
- Zentrierte Darstellung des Inhaltes
- Speicherung pro Monat in einer lokalen SQLite-Datenbank
- Pastellfarben je Feld

## Build

- `npm run build`
- `npm start`
