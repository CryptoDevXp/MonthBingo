# Month Bingo

A small Node.js + TypeScript app for creating a 4x4 bingo board for each month with pastel-colored cells.

## Getting started

1. `npm install`
2. `npm run dev`
3. Open your browser at `http://localhost:3001`

## Features

- 16 fields in a square 4x4 grid
- Add text to each field
- Centered content layout
- Per-month storage in a local SQLite database
- Pastel color styling for each field

## Build

- `npm run build`
- `npm start`
